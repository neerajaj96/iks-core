# Source snapshots

The pinned files under `cache/` are intentionally not redistributed from this
public repository. Several sources carry non-commercial, educational-use, or
reference-use terms, and the repository's top-level MIT license does not
override those terms.

To rebuild the graph or run the test suite, obtain each source under its own
terms and place it under `cache/` using the filename listed in
`../data/sources.json`. Verify the recorded SHA-256 before building. The
published graph artifacts are available under `../../docs/kg/`.
