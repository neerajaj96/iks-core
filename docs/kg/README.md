# IKS Knowledge Graph artifacts

Published at <https://neerajaj96.github.io/iks-core/kg/>.

Version 0.1.0, generated 2026-10-22 from the source pipeline in
[`kg/`](https://github.com/neerajaj96/iks-core/tree/main/kg). The versioned
release is [`kg-v0.1.0`](https://github.com/neerajaj96/iks-core/releases/tag/kg-v0.1.0).

## Files

- `iks-kg.ttl.gz` — Turtle serialization, gzip-compressed.
- `iks-kg.nt.gz` — N-Triples serialization, gzip-compressed.
- `iks-kg.jsonld.gz` — JSON-LD serialization, gzip-compressed.
- `iks-kg.shacl.ttl` — SHACL shapes used for validation.
- `iks-kg.context.jsonld` — JSON-LD context.
- `coverage.json` — coverage counts by graph area.
- `manifest.json` — version, counts, artifact sizes, and hashes.
- `SHA256SUMS` — checksums for the downloadable artifacts.
- `summary.md` — build summary.

Verify downloads with:

```sh
sha256sum -c SHA256SUMS
```
